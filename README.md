# Miku-Mon

Tiny original pocket-monster wander-and-battle game for GitHub Pages.

**Not Pokémon.** Original creatures only (Mikachu, Tetoflame, Froggo, Horsie).

## Watch

After you enable Pages (Settings → Pages → Deploy from `main` / `/root`):

https://jaxoncarelos.github.io/miku-mon/

## Play loop (Discord)

Ping Miku with something like:

> play miku-mon for 30 seconds

She will:

1. Load `save.json`
2. Simulate ~30s of wandering / battles
3. Commit an updated `save.json`
4. You refresh the Pages site to see her progress

Controls if you play locally: WASD / arrows, space to heal at the brown center tile.
